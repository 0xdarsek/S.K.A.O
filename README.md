# S.K.A.O — Is A Cybersecurity Certification Roadmap Platform

A web-based platform that guides visitors through cybersecurity career paths, showing which
certifications to earn and in what order — built for **CT050-3-2-WAPP (Web Applications)** at
Asia Pacific University.

## 📌 Project Overview

**CertPath** lets guests browse cybersecurity career roadmaps without an account. Registered
members can track their certification progress, bookmark certs, and take self-assessment
quizzes per path. Admins manage all roadmap and certification content.

### Launch Career Paths
- 🎯 Penetration Tester
- 🔴 Red Team Operator
- 🛡️ SOC Analyst
- 🕵️ Threat Hunter

- **Module:** CT050-3-2-WAPP – Web Applications
- **Tech stack:** ASP.NET, C#, SQL Server (local), HTML5, CSS, JavaScript
- **Team size:** 4
